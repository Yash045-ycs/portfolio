# Yash Chirag Shah - Personal Portfolio

This project is a personal portfolio website designed to showcase my skills, projects, and professional background as a web developer.

## Overview
The website serves as a digital resume and project showcase, providing visitors with information about my technical expertise and recent work.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Key Features
- **Responsive Design:** Optimized for various screen sizes and devices.
- **Smooth Scrolling:** Intuitive navigation experience for users browsing through sections.
- **Skills Marquee:** A visually engaging scrolling track highlighting core technical skills.
- **Contact Section:** Dedicated area for professional inquiries.

## How to View
1. Clone this repository to your local machine.
2. Open `index.html` in your preferred web browser to view the portfolio locally.
