# Responsive Personal Web Portfolio & Landing Page

A responsive single-page web portfolio and landing page featuring interactive smooth scrolling and custom layout styling.

## Repository Structure

- `index.html`: The main HTML layout and content structure for the web portfolio.
- `style.css`: Custom CSS styles including responsive design layouts and navigation bar styling.
- `script.js`: JavaScript functionality for smooth scrolling and interactive user interface behaviors.

## Usage

Open `index.html` in any modern web browser to view the portfolio.
